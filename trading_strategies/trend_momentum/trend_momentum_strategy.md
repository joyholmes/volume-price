# 证券ETF趋势动量策略说明文档

## 一、策略概述

### 1.1 策略背景
本策略是一个针对证券ETF（512880.SH）的趋势跟踪策略，结合了趋势、动量和波动率三个维度的分析，同时包含完善的仓位管理和风险控制机制。

### 1.2 策略特点
- 多维度信号系统
- 动态仓位管理
- 双重止损机制
- 板块联动分析

## 二、策略逻辑

### 2.1 信号系统
1. **趋势判断**
   - 三均线系统（5/20/60日）
   - 趋势确认条件：快线>中线>慢线
   - 价格位置：收盘价>中期均线

2. **动量分析**
   - ROC（变化率）：衡量短期动量
   - RSI（相对强弱）：判断超买超卖
   - MACD：确认趋势动量

3. **波动率过滤**
   - ATR指标：衡量市场波动性
   - 波动率均线：过滤高波动期

### 2.2 交易规则

#### 买入条件
1. 趋势向上：
   - MA5 > MA20 > MA60
   - 价格 > MA20

2. 动量确认：
   - ROC > 阈值（2%）
   - RSI > 超卖线（30）
   - MACD柱 > 0

3. 波动率适中：
   - ATR < ATR均线

#### 卖出条件
1. 趋势反转：
   - MA5 < MA20 < MA60
   - 价格 < MA20

2. 动量减弱：
   - ROC < -阈值
   - RSI > 超买线（70）
   - MACD柱 < 0

## 三、仓位管理

### 3.1 建仓策略
- 初始建仓：30%
- 加仓步长：20%
- 最大仓位：100%

### 3.2 加仓条件
- ROC维持正值
- RSI未达超买
- 当前仓位<最大仓位

## 四、风险控制

### 4.1 止损机制
1. **固定止损**
   - 止损比例：5%
   - 相对建仓价格

2. **追踪止损**
   - 止损比例：8%
   - 相对最高价格

### 4.2 波动率控制
- 高波动期降低交易频率
- ATR指标过滤剧烈波动
